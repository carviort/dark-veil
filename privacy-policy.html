Dark Veil — Privacy Policy

Last updated: 4 August 2026

Dark Veil does not collect, store or transmit any personal data.

What the extension stores

Dark Veil saves your display preferences using the browser's local storage API (chrome.storage.local). This covers:

  • whether dark mode is enabled, per website domain;
  • the rendering method chosen for each domain;
  • brightness, contrast and warmth values;
  • your interface language preference.

This data never leaves your device. It is not accessible to the developer or to any third party, and it is deleted when you uninstall the extension.

What the extension does not do

  • It makes no network requests of any kind.
  • It contains no analytics, telemetry or tracking.
  • It contains no remote code.
  • It does not read the text, form fields, cookies or credentials of the pages you visit.
  • It does not record your browsing history.

Why it requests access to all websites

The extension's only feature is applying a dark colour scheme to web pages, and it cannot know in advance which sites you will want darkened. Access is used solely to inject a <style> element containing CSS filter rules, and optionally to add a CSS class to elements that carry a background image. Nothing is read from the page and nothing is sent anywhere.
